# Universal Video Director — Claude Code Skill v2 (ภาษาไทย)

**เวอร์ชันขยายจาก Viral Video Director ให้ใช้กับวิดีโอทุกแนว** ไม่ใช่แค่ตลกหรือ TikTok: รีวิวสินค้า, เปรียบเทียบ, ขายของ, โฆษณา, UGC, สาธิต, สอน, สาระ, บทสัมภาษณ์, พอดแคสต์, สารคดี, เรื่องเล่า, ภาพยนตร์สั้น, แบรนด์, อสังหาริมทรัพย์, ท่องเที่ยว, ไฮไลต์ไลฟ์, คลิปตัดสั้นจากคลิปยาว และคลิปผสมหลายสไตล์

เป้าหมายคือให้ Claude Code **คิดแบบทีมผลิตวิดีโอมืออาชีพ** แล้วเลือกเทคนิคที่เหมาะกับคลิปนั้น: คิดคอนเซปต์ → วาง Hook → ตรวจข้อเท็จจริง → เขียนบท → สร้างสไตล์ภาพ/วาด SVG/เขียนพรอมป์ภาพ → จัดฉาก/ตัดต่อ → วางเสียง/ซับ → เรนเดอร์เมื่อมีเครื่องมือ → QA → เตรียมเผยแพร่

> ชื่อคำสั่งใหม่คือ **`/universal-video-director`** เพื่อสื่อว่ารองรับทุกหมวด แพ็กนี้สร้างใหม่แยกจาก Skill เดิม จึงไม่ได้ลบหรือเขียนทับ Skill เดิมของคุณ หากต้องการใช้ตัวใหม่ให้เรียกชื่อใหม่ ไม่ต้องเรียก `/viral-video-director`.

## ติดตั้งใน Claude Code

1. แตกไฟล์ ZIP แล้วคัดลอกโฟลเดอร์ `universal-video-director` ทั้งโฟลเดอร์
2. วางใน `.claude/skills/` ของโปรเจกต์ที่ต้องการ (โครงสร้างสุดท้าย `.claude/skills/universal-video-director/SKILL.md`)
3. หากต้องการใช้ทุกโปรเจกต์ วางที่ `~/.claude/skills/universal-video-director/` แทน
4. เปิด Claude Code ที่โปรเจกต์นั้น หรือเปิดเซสชันใหม่ถ้า Skill ยังไม่ถูกค้นพบ
5. เรียก `/universal-video-director FACTORY ...` หรือเลือกโหมดด้านล่าง

**Skill ใช้ได้โดยไม่ต้องติดตั้ง Remotion** สำหรับโหมดวางแผน เขียนบท รีวิวไฟล์ และวาดเวกเตอร์ แต่ถ้าต้องตัดต่อวิดีโอจริงต้องมีเครื่องมือ/ไฟล์สื่อเหมาะกับงานนั้น (เช่น FFmpeg, Remotion, editor ที่ติดตั้งอยู่, ไฟล์เสียงจริง และสิทธิใช้งานสื่อ)

## 7 โหมดทำงาน

| โหมด | ใช้เมื่อ | สิ่งที่ได้ |
|---|---|---|
| `IDEATE` | คิดช่อง/แนว/ไอเดียวิดีโอ | วิเคราะห์ผู้ชม, คอนเซปต์, 3 Hook, มุมต่างๆ |
| `SCRIPT` | ต้องการคอนเทนต์/บทพูด | บท, เรื่อง, ลำดับฉาก, คำขึ้นจอ, CTA |
| `DESIGN` หรือ `DRAW` | ออกแบบ/วาดภาพ | Style bible, SVG, องค์ประกอบกราฟิก, prompt ภาพ และอาร์ตเวิร์กเมื่อมีเครื่องมือ |
| `EDIT` | มีฟุตเทจหรือโปรเจกต์แล้ว | ตรวจไฟล์, ประกอบไทม์ไลน์, ตัดต่อ, ซับ, เสียง, เรนเดอร์ตามเครื่องมือ |
| `AUDIT` | ต้องการให้ตรวจคลิป | วิจารณ์ภาพ/เสียง/จังหวะ/ข้อเท็จจริง/กฎหมายแบบ read-only |
| `REPURPOSE` | ตัดคลิปยาวเป็นหลายคลิป | หาช่วงไฮไลต์ที่ไม่บิดความหมาย, cutdown, ปรับอัตราส่วน |
| `FACTORY` | ต้องการผลิตครบวงจร | ทำครบทุก Gate ภายในข้อจำกัดสิทธิ/เครื่องมือ/งบ |

## ตัวอย่างคำสั่งพร้อมใช้

### 1) รีวิวสินค้าแบบมืออาชีพ

```text
/universal-video-director FACTORY
ทำวิดีโอรีวิวสินค้าที่ฉันให้รูป/ฟุตเทจจริง ความยาวประมาณ 60–90 วินาที
ผู้ชมคือคนกำลังตัดสินใจซื้อ เน้นความน่าเชื่อถือและข้อดีข้อเสีย
คิด Hook 3 แบบ เปรียบเทียบด้วยเกณฑ์ที่ตรวจสอบได้
ห้ามแต่งผลการทดสอบ รีวิวใช้งานจริง หรือข้อมูลราคาเอง
ทำบท/ช็อต/ซับ/กราฟิกและตัดต่อจากสื่อที่มี ก่อนส่งออกต้องตรวจ QA
```

### 2) คลิปขายของ/ยิงโฆษณา

```text
/universal-video-director FACTORY
สร้างวิดีโอขายสินค้าจากไฟล์สินค้าและเงื่อนไขที่ฉันให้
ทำแบบ 15 และ 30 วินาที แนวตั้ง 9:16
วิเคราะห์จุดเจ็บปวดลูกค้า ทำ Hook 3 แบบ
ใช้เฉพาะสเปก ราคา ส่วนลด รีวิวลูกค้า และคำเคลมที่ยืนยันได้
ตัดต่อให้สินค้าชัด ข้อเสนออ่านง่ายและ CTA ตรงเป้าหมาย
สร้างเวอร์ชัน A/B โดยเปลี่ยนเฉพาะ Hook
```

### 3) คลิปตลกเล่าเรื่อง

```text
/universal-video-director FACTORY
ทำซีรีส์ตลกโยธาปะทะไฟฟ้า 25–35 วินาที
มุขคม ตบมุขหักมุม สไตล์ภาพ 2D Motion Comic
เขียน Hook 3 แบบ วาดตัวละครให้คงที่ ใช้เสียงพูดจริง/เสียงที่มี
ทำบท ตัดต่อ Remotion ซับเด้ง และเช็กจังหวะเงียบก่อนมุข
```

### 4) คลิปสอน/อธิบาย

```text
/universal-video-director FACTORY
สร้างคลิปสอนหัวข้อที่ฉันให้ ความยาว 3–5 นาที แนวนอน 16:9
อธิบายเป็นขั้นตอน วาดไดอะแกรมและไฮไลต์ตามคำอธิบาย
ใช้ Hook แบบตั้งคำถาม ไม่เร่งตัดตอนสำคัญ
ตรวจความถูกต้องและทำซับอ่านง่าย พร้อมเวอร์ชันคลิปสรุป 45 วินาที
```

### 5) คลิปแบรนด์/อสังหาริมทรัพย์/งานก่อสร้าง

```text
/universal-video-director EDIT
ตัดวิดีโอพาชมบ้านจากฟุตเทจที่ฉันให้ ความยาว 60–90 วินาที
สไตล์พรีเมียม เน้นรายละเอียดงานจริง ภาพนิ่งนุ่ม เพลงไม่แย่งเสียง
ทำไตเติลแสดงพื้นที่และฟังก์ชันเฉพาะที่ยืนยันได้
ห้ามแต่งภาพจนทำให้ผู้ชมเข้าใจผิดเรื่องสภาพจริง
```

### 6) สัมภาษณ์/พอดแคสต์

```text
/universal-video-director REPURPOSE
ใช้วิดีโอสัมภาษณ์ที่ฉันให้ ตัด 5 ไฮไลต์ความยาว 30–60 วินาที
เลือกประโยคเด็ดพร้อม timecode ต้นฉบับ
รักษาความหมายและคำขยายสำคัญของผู้พูด
จัดเฟรมคนพูดใหม่ ใส่ซับ/ชื่อผู้พูด และเช็กว่าการตัดไม่บิดบริบท
```

### 7) คิดไอเดียหลายแนวเพื่อเทสต์ช่องใหม่

```text
/universal-video-director IDEATE
วิเคราะห์ไอเดีย 15 คลิป แบ่งเป็นรีวิว ตลก ความรู้ ขายของ และเรื่องเล่า
จัดเป็นซีรีส์ พร้อมกลุ่มผู้ชม มุม Hook 3 แบบต่อแนว
เสนอเกณฑ์เลือกคลิปทดลองและตัวชี้วัดจริงหลังเผยแพร่
```

## โครงสร้างแพ็ก

- `SKILL.md` — หัวใจของระบบ และกติกาเลือก Format, Hook, ทีมผลิต, การตัดต่อและ QA
- `references/01-15` — คู่มือเฉพาะด้านและเฉพาะแนว (ตลก, รีวิว, ขายของ, UGC, การสอน, สัมภาษณ์, งานแบรนด์, ตัดไฮไลต์, Hook, ศิลป์, เสียง, QA)
- `templates/universal-brief.md` — แบบบรีฟกลางสำหรับทุกแนว
- `templates/story.schema.example.json` — โครงสร้างไทม์ไลน์กลาง ใช้ได้กับวิดีโอมีตัวละคร/ไม่มีตัวละคร มีเสียง/ไม่มีเสียง แนวตั้ง/แนวนอน
- `templates/claims-ledger.csv` — ติดตามคำโฆษณาและข้อเท็จจริงก่อนเผยแพร่
- `templates/asset-manifest.csv` — ที่มาและสิทธิการใช้ภาพ/เสียง/เพลง
- `templates/release-checklist.md` — ตาราง QC/ความพร้อมก่อนเผยแพร่
- `examples/` — ตัวอย่างตลก, รีวิว, ขายของ, สอน และสัมภาษณ์ (ตัวอย่างที่ไม่มีไฟล์สื่อจริงเป็นโครงร่าง ไม่ใช่คลิปที่ผลิตแล้ว)
- `scripts/validate_story.py` — ตรวจ JSON และไทม์ไลน์ทุกรูปแบบ
- `scripts/check_claims.py` — เตือนและบล็อกคำเคลมสำคัญที่ยังไม่มีหลักฐาน
- `scripts/draw_character_svg.py` — วาดตัวละคร SVG ตัวอย่าง
- `scripts/draw_title_card_svg.py` — สร้างการ์ดข้อความ/หัวข้อแบบ SVG สำหรับรีวิว ขายของ ความรู้ และภาพประกอบทั่วไป (แนวตั้งและแนวนอน)
- `scripts/qa_video.py` — ตรวจข้อมูลเทคนิคของ MP4 ด้วย ffprobe
- `tests/` — ชุดทดสอบ validator

## ตรวจตัวอย่างบนเครื่อง

```bash
python scripts/validate_story.py examples/engineers-comedy.json
python scripts/validate_story.py examples/product-review.json
python scripts/validate_story.py examples/product-sales.json
python scripts/validate_story.py examples/education-explainer.json
python scripts/validate_story.py examples/interview-highlight.json
python scripts/check_claims.py examples/claims/product-review.csv
python scripts/check_claims.py examples/claims/product-sales.csv
python scripts/check_claims.py examples/claims/education-explainer.csv
python -m unittest discover -s tests -v
```

ไฟล์ `templates/claims-ledger.csv` ใส่คำเคลม **UNVERIFIED** เป็นตัวอย่างตั้งใจให้คำสั่ง `check_claims.py` แสดง FAIL จนกว่าจะมีหลักฐานหรือยกเลิกคำเคลมนั้นจริงๆ

## ตัดต่อด้วยโค้ดและ Remotion

หากโปรเจกต์ต้องการ Motion Graphics หรือวิดีโอสร้างจากข้อมูลเป็นหลัก ให้ใช้ Remotion (ทำงานร่วมกับ Claude Code) และทักษะทางการของ Remotion ตามที่ได้รับอนุญาต:

```bash
npx skills add remotion-dev/skills
```

เอกสารอ้างอิงทางการ:
- Claude Code skills: https://code.claude.com/docs/en/skills
- Remotion Agent Skills: https://www.remotion.dev/docs/ai/skills
- Remotion render: https://www.remotion.dev/docs/render
- Remotion licensing: https://www.remotion.dev/docs/license

**หมายเหตุ:** Skill เป็นคู่มือ, โค้ด, ตัวตรวจ, เทมเพลต และตัวอย่าง **ไม่รวมการจ่ายเงินสำหรับ AI ภาพ/เสียง/วิดีโอ, ไม่รับประกันไวรัล, ไม่ประกอบ MP4 จากสื่อที่ไม่มี และไม่เผยแพร่วิดีโอเอง**. ถ้ามีฟุตเทจหรือเสียงครบและเครื่องมือพร้อม Claude Code จึงจะตัดต่อ/เรนเดอร์ตามจริงได้.
