# Existing footage repurposing, livestream highlights, multi-format and long-form

## Source-first workflow
1. Inventory source clips and frame rates/resolutions/orientations, audio channels, licenses, transcript/timecodes, chapter structure, names/terms.
2. Keep original masters untouched; use proxies or copies where useful. Tag a source timecode and quotation for each selected highlight.
3. Select clips by **complete idea**, not isolated shock line. Preserve disclaimers and key answer context.
4. Make a paper cut before editing; plan framing per platform and mobile safe zones.
5. Reframe, add graphics, captions, opening context and end CTA appropriate to each platform. Preserve meaning and appearance.
6. Export separate 9:16 / 16:9 / 1:1 / 4:5 versions only as requested; inspect actual crops.

## Highlight selection score
Score 0–5 for self-contained meaning, relevance to audience, genuine emotion/utility, source fidelity and visual feasibility. Reject any snippet whose apparent meaning differs from its source even if it looks clickable.

## Long-form planning
Design title/promise, section outline, chapter hooks, visual diversity, recurring graphics, audience questions and chapter summaries. Keep breathing room; cut repetition, but don't accelerate complex explanations unnecessarily. Chapters/timecodes are useful but must reflect the rendered runtime.

## Special cases
- Split-screen reactions and duet content: check rights/fair use applicability; don't assume a clip is free to reuse.
- Livestream: identify context that happened earlier so snippets remain fair.
- Webinars/tutorials: preserve key steps and source screen details; add visual hierarchy and chapter cards.
- Multiple aspect ratios: build a composition-aware layout (not stretch/distort).
